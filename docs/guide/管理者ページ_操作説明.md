# MOLA Timing 管理者ページ 操作説明

**対象 URL:** https://oic-timing-admin.mola-timing-okayama.com/  
**対象:** 岡山国際サーキット Live Timing の運営・事務局の管理者  
**公開日:** 2026-08-22

一般のお客様向けページ（Live / 履歴）とは別の、**管理者専用**の画面です。  
この URL を一般公開したり、SNS や掲示に載せたりしないでください。

---

## 1. 最初に知っておくこと

管理画面では次の 3 つができます。

| メニュー | できること |
|----------|------------|
| **履歴データ** | 過去の走行結果を、日付またはセッション単位で公開画面から外す／戻す。表示名の変更 |
| **Live表示** | Live Timing 表の列の並び・名称・表示／非表示・プルダウン内容の変更 |
| **ユーザー** | 管理者アカウントの追加・パスワード変更・削除 |

**やってはいけないこと・起きないこと**

- 「非表示」にしても、計測の生データは消えません。いつでも再表示できます
- Live の列を変えても、順位やタイムの**数値そのもの**は変わりません。見出しの見せ方だけが変わります
- 管理画面では位置情報の許可は不要です

## 4. 履歴データ（過去結果の公開管理）

お客様が見る履歴（リザルト・カレンダー）に出す／出さないを決めます。  
**削除ではありません。** 非表示にしてもデータはサーバーに残ります。

### 4.1 日付ごと（その日のデータ全部）

1. **履歴データ** を開く
2. 左側（または一覧）の日付を確認する。新しい日付が上です
3. 出さない日は **非表示にする** を押す
4. カレンダーや履歴一覧から、その日が消えます
5. 戻すときは同じ日付の **再表示する** を押す

日付をタップすると、その日のセッション一覧が開きます。

### 4.2 セッションごと（例: その日の AM 走行だけ）

1. 対象の日付を選ぶ
2. セッション名の右にある **非表示にする** を押す
3. そのセッションだけ、履歴から消えます
4. 戻すときは **再表示する**

日付を非表示にすると、中のセッションもまとめて公開されません。  
日付は出したまま、一部セッションだけ隠す、という使い方ができます。

### 4.3 表示名の変更（大会名・セッション名など）

計測データに入っている名前を、公開画面だけ別の表記にできます。

1. 対象セッションの **表示名** を押す
2. 次の項目を必要に応じて書き換える

| 項目 | 例 |
|------|-----|
| カテゴリ | クラス・カテゴリ名 |
| ラウンド | 第○戦 など |
| セッション | AM走行、公式予選、決勝 など |
| 大会 | イベント名 |

3. **保存** を押す
4. 空欄にして保存すると、上書きをやめて元の計測データ名に戻ります

変更後は、履歴ページの一覧・詳細・CSV のファイル名にも反映されます。

### 4.4 よくある使い方

| やりたいこと | 操作 |
|--------------|------|
| テスト走行を公開したくない | そのセッションを **非表示にする** |
| その日まるごと出したくない | 日付を **非表示にする** |
| 「AM走行」を分かりやすい名前にしたい | **表示名** でセッション名を変更して保存 |
| 間違えて隠した | **再表示する**（データは残っています） |

## 5. Live表示（タイミング表の見た目）

Live Timing の表ヘッダー（P / No. / Class / Behind など）を、運営の好みに合わせます。

### 5.1 保存するまで Live は変わりません

並びや名前をいじっただけでは、お客様の画面は変わりません。  
右上の **保存して Live に反映** を押した時点で、開いている Live ページにもすぐ届きます（再読み込み不要）。

未保存のときは「未保存の変更あり」と出ます。  
間違えて変えただけなら、保存せず別メニューへ移動すると破棄されます。確実に戻すなら **既定に戻す** → **保存して Live に反映** です。

### 5.2 列の並び替え

各行の左の **▲ / ▼** で順番を変えます。  
上の「プレビュー（表示中の列）」で、Live に出る並びを確認できます。

### 5.3 表示／非表示

行の **表示** チェックを外すと、その列は Live に出ません。  
例: セクター（S1 / S2 / S3）を出さない、ピット回数を出さない、など。

- 決勝以外でも使う列は、**少なくとも 1 つは表示**にしてください
- **決勝のみ** と付いている列（順位変動 ▲▼）は、決勝セッションのときだけ出ます

### 5.4 名称の変更

右側の入力欄が、表のヘッダーに出る名前です。  
例: `P` → `順位`、`No.` → `車番`、`Name` → `ドライバー`

24 文字までです。空でも構いません（状態ランプなど、もともと名前が無い列）。

### 5.5 プルダウン（Car / Behind / Laps など）

一部の列は、お客様がヘッダーをタップして表示を切り替えられます。  
**プルダウン** を押すと、次が変えられます。

| 操作 | 意味 |
|------|------|
| **出す** | お客様のメニューにその項目を出す |
| 名称の入力 | メニューに出る文字（例: Behind → 先頭差） |
| **初期** | ページを開いたときに最初に出す項目 |

プルダウンがある列では、出す項目を **1 つ以上**残してください。  
1 つだけにすると、お客様側は切替メニューではなく、その名前の固定見出しになります。

よく触る列の目安:

| 列（画面上の英字キー） | 中身 |
|------------------------|------|
| status | ピット中などのランプ |
| pos | 総合順位 |
| chg | 順位変動（決勝のみ） |
| pic | クラス内順位 |
| nr | 車番 |
| class | クラス |
| driver | ドライバー名 |
| car | 車両名 / チーム名 |
| laps | 周回 / 通過時刻 / 前回タイム |
| gap | 先頭差 (Behind) / 前車差 (Gap) |
| best | ベストタイム / ベスト周 |
| s1 / s2 / s3 | セクタータイム |
| pit | ピット回数 / ピットタイム |

### 5.6 確認のしかた

1. 管理画面で変更して **保存して Live に反映**
2. 別タブで https://mola-timing-okayama.com/ （または関係者向け URL）の Live を開く
3. 表のヘッダーが変わっていることを確認する

すでに Live を開いている端末にも、保存とほぼ同時に届きます。届かないときは、そのページを再読み込みしてください。

## 6. ユーザー（管理者アカウント）

### 6.1 追加

1. **ユーザー** を開く
2. 下の「管理者を追加」にユーザー名とパスワードを入れる
3. **追加** を押す

| 項目 | 規則 |
|------|------|
| ユーザー名 | 英数字と `.` `_` `-` のみ。3〜32 文字 |
| パスワード | **10 文字以上** |

日本語のユーザー名は使えません。

### 6.2 パスワード変更

1. 対象ユーザーの **パスワード変更** を押す
2. 新しいパスワード（10 文字以上）を入れて **変更**
3. その人は、いま入っているログインが切れます。再度ログインが必要です
4. **自分自身**のパスワードを変えた場合は、この画面からもログアウトします。新しいパスワードで入り直してください

### 6.3 削除

- 対象の **削除** → 確認ダイアログで実行
- 自分自身は削除できません
- 管理者が 1 人だけのときは削除できません（先に別の人を追加する）

## 8. 困ったとき

| 症状 | 確認すること |
|------|----------------|
| ログインできない | ユーザー名／パスワードの打ち間違い。大文字小文字も一致させる |
| 管理 URL が Live になる | アドレスが `oic-timing-admin` か確認。一般向けドメインでは管理画面は出ません |
| 履歴から消したのにデータが心配 | 非表示は公開から外しているだけです。**再表示する**で戻ります |
| Live の列を変えたのに変わらない | **保存して Live に反映** を押したか。未保存のまま別画面へ行っていないか |
| プルダウンが保存できない | その列を表示しているなら、プルダウンの「出す」を 1 つ以上オンにする |
| 決勝の ▲▼ が出ない | 列 `chg` が非表示になっていないか。予選・練習では仕様上出ません |
| 操作中にログイン画面へ戻った | しばらく操作が無かったか、パスワード変更後です。入り直す |
| ページが真っ黒／エラー | 再読み込み。続く場合は運営担当へ（この説明書と、操作したメニューを添える） |

## 9. 運用上のお願い

1. 管理 URL とパスワードは、必要な担当者だけが持つ
2. 使い終わったら **ログアウト** する（共用 PC の場合は特に）
3. 履歴の非表示は「消す」ではなく「お客様に見せない」操作として使う
4. Live の見た目を大きく変えるときは、本番セッションの直前ではなく、余裕のある時間に保存して確認する
5. 分からない操作は、試す前にこの説明書の該当節を確認する

問い合わせ先は、この説明書をお渡しした担当者までお願いします。
