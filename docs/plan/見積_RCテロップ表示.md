## 1. 見積の位置づけ

### 1.1 本見積の対象

MOLA 計測が当日 CSV（`Telop-YYYYMMDD*.csv`）を上書き保存する前提で、更新を Receiver が拾い、サーバー経由で次を出すための **追加開発費用** です。

- **RCメッセージページ**（当日履歴 + Result と同様のカレンダー）
- **Live 最下行 1 行**（提示中のみ。RED / SC / FCY 等の旗を優先）

SMIS XML の `Message` とは別系統です。ヘッダーの TrackStatus（GREEN/FCY/SC/RED）連動は含みません。

### 1.2 既存範囲との関係

| 内容 | 既存 LiveTiming | 本見積（追加） |
|------|----------------|----------------|
| SMIS 計測データの受信・Live / Result 表示 | ○ | — |
| SMIS XML `Message` の受信経路 | ○（フロント未使用） | —（統合しない） |
| **Telop CSV の監視・取込** | **×** | **○** |
| **RCメッセージページ（履歴・カレンダー）** | **×** | **○** |
| **Live 最下行の RC 1 行（旗優先）** | **×** | **○** |
| SideMenu / Live 状態 / ingest / SQLite | 既存を改修 | ○（改修分を本見積に含む） |
| ヘッダー TrackStatus のテロップ連動 | — | ×（オプション B） |
| 本番デプロイ | — | ×（オプション C） |

## 6. お見積り条件・免責

1. **CSV 格納場所**  
   未定のため、標準では監視フォルダを設定項目にする。場所が分かっても追加費用は原則なし（パスを入れるだけ）。現場作業や本番反映はオプション C。

2. **ファイル名**  
   未定のため `Telop-YYYYMMDD*.csv` とする。大きく変わる場合は再見積。

3. **本番未含む**  
   標準はローカル表示テストまで。本番デプロイはオプション C。

4. **見積有効期限・範囲変更**  
   TrackStatus 連動、SMIS `Message` との統合、ファイル形式の大幅変更は再見積。

## 7. 提案先への説明文（コピー用）

> 計測側が当日テロップ CSV を上書き保存する運用に合わせ、レースコントロールメッセージを LiveTiming に出す追加開発です。  
> RC 専用ページに提示中ハイライト / 解除済みグレーの履歴と、Result と同様のカレンダーを備え、Live 画面最下行には旗（赤旗 → SC → FCY）を優先した 1 行を出します。  
> 標準見積：**5.0 人日、税込 275,000 円**（単価 50,000 円/人日。うち既存改修 1.75 人日、新規 2.25 人日、設計・テスト等 1.0 人日）。本番反映はオプションです。
